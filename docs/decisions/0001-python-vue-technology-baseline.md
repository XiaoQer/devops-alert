# ADR 0001：Python 与 Vue 技术基线

## 状态

已接受，分阶段实施。数据库选择已由 ADR 0002 更新为 MySQL 8.4。

## 背景

事故平台需要统一核心控制器、可独立扩缩容的诊断与分析 Worker，以及面向操作员的统一 UI。技术选型需要支持强契约输入、异步持久任务、独立测试和前后端解耦，同时避免首期引入不必要的分布式基础设施。

## 决策

- 后端及 Worker 使用 Python；
- HTTP API 使用 FastAPI，契约模型使用 Pydantic；
- 数据访问使用 SQLAlchemy，迁移使用 Alembic；具体数据库由独立持久化决策确定；
- 前端使用 Vue 3、TypeScript、Vite 和 Pinia；
- OpenAPI 是前后端接口事实来源，前端从契约生成类型；
- 首期持久任务和租约由关系数据库承载，不引入 Kafka；
- 后端、前端和端到端测试分别使用 Pytest、Vitest 和 Playwright；
- 前后端独立构建并默认成套部署，可选 Worker 独立部署。

## 结果

阶段 1 可以围绕同一套领域契约建立 API、Worker 和 UI 工程基线。关系数据库同时承载事务数据与首期持久任务，降低早期运维复杂度；如果未来吞吐量或隔离需求超过关系数据库任务模型，再通过版本化任务契约替换传输层。

本决策不代表任何能力已经实现。运行时版本、依赖锁定、项目目录和本地运行方式将在实施计划中确定。
