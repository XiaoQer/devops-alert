# Incident 监控取证验证记录

## 自动化结果

- 后端统一验证：449 项测试全部通过；Ruff、格式检查和 mypy 通过；总覆盖率 90.04%。
- 数据库：测试套件反复执行从 base 升级到 head、降级到 base；包含 0019 取证表、约束和带取证活动数据的降级路径。
- 前端：26 个测试文件、79 项测试全部通过；Vite 生产构建成功。

## 已验证行为

- 新 Incident、唯一自动 EvidenceRun 和待执行任务在同一事务创建；并发评估收敛后不会重复创建自动运行。
- Prometheus、Elasticsearch、SkyWalking 可按环境选择唯一启用来源；缺少来源、缺少服务、永久错误和暂时错误均形成有界结果。
- 暂时错误最多重试五次；过期租约可回收；最后一次失败会收敛为失败证据而不是无限任务。
- 单来源失败保留其他来源已成功证据；全来源可用时运行可完成为成功。
- 人工重新取证使用持久化幂等键，不覆盖历史；存在活动运行时返回当前运行编号。
- API 最多返回 50 条历史运行和 100 条证据，不返回 Secret 或用户提交的监控查询。
- Incident 详情提供监控取证分区、历史选择、中文状态、异常项优先展开及来源状态摘要。

## 尚未验证

- 尚未连接用户测试环境中的真实 Prometheus、Elasticsearch 和 SkyWalking 执行只读契约检查。
- 尚未在真实浏览器中验收新 Incident 自动取证、历史切换和单来源失败展示。
